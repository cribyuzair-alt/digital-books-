Ye library tayari ke liye hai. Asal sarkari kitab (jo board exam ki bunyad hai) hamesha official source se lein:

  • PCTB E-Books Portal — Punjab ki Class 1–12 ki tamam kitabein muft PDF mein (ab PECTAA ke under).
  • Apne board ki website (BISE Lahore, Karachi, Rawalpindi, Peshawar waghera) par past papers aur model papers bhi muft milte hain — exam se pehle zaroor dekhein.
  • Is page ke har book page par "Model Paper" ka khaka aam Punjab Board pattern par hai; apne board ke current model paper se mila kar tasdeeq kar lein, kyunke pattern waqt ke saath badal sakta hai.
